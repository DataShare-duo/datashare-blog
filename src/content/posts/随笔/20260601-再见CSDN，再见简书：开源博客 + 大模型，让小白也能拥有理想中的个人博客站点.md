# 背景

一直以来，我都在 CSDN 和简书上断断续续地写点东西。说实话，当初选择它们的原因很简单：免去自己搭建的麻烦，写完就能发，还有一定的社区流量，但时间一长，问题也越来越难以忍受

**首先是审核**

你永远不知道哪一句话会触发敏感词，有时一篇纯技术文章，反复修改好几次才能发出去，而等到审核通过，写作时的那股热情早就被消磨光了

**更让人头疼的是广告**

页面中的广告，是越来越多，已经严重影响阅读体验，作为一个作者，看着自己的文字被这些内容包围，心里真的很不是滋味。读者来是为了看内容，不是为了看广告，而我却没办法给他们一个干净的阅读环境

这里得吐槽一下 CSDN，随意强迫用户关注博主，才能阅读全文，其实作者并没有这样的设置


于是，终于下定决心：**注销CSDN、简书，自建博客网站，搬家**

# 博客需求
- 干净、简洁的页面，没有广告
- 专注于阅读，排版舒服
- 我能完全掌控内容，不用再看任何平台的脸色

GitHub Pages 的免费托管加上各种开源静态博客框架，显然是最合适的选择。问题来了——我虽然会写点后端代码，但真要自己从零设计一个漂亮的博客主题，调整各种细节配置，还是有点吃力

但自从有了大模型，自己以前一直有自建博客网站的想法终于可以实现了，不需要深入了解前端知识，遇到样式问题，大模型可以解释得非常详细，只需要把自己的需求告诉它，大模型就像身边一个耐心又全能的同事，不但告诉我该修改哪个文件、哪一行配置，甚至连 CSS 代码都直接帮我写好

基于开源博客：https://github.com/saicaca/fuwari

# 实现
**工具**： DeepSeek TUI

**api消耗金额**：10元多

**新增功能**：
1. 博客样式、布局修改
2. 增加评论功能
3. 分类支持二级
4. 增加文章阅读量
5. 文章列表封面图片，是否在文章详情页展示，在 Frontmatter 中增加参数 `showCoverInPost`，默认 `true`（展示）



# 现在的博客：简洁、美观、无广告

打开现在的博客地址，第一感觉就是——干净。

没有弹窗，没有广告条，没有莫名其妙的热门推荐。文章就是文章，排版舒服，阅读专注

对我来说，这不仅是换了一个写东西的地方，更是把写作的主动权重新拿回到了自己手里。我不需要担心哪天平台规则一变，自己写下的内容就被折叠、限流甚至消失。每一次改动、每一点优化，都是我自己说了算

因为有开源项目和 AI 的帮助，建站这件事，已经从“需要折腾很久”变成了“一个几天就能搞定的小项目”

如果你也受够了那些广告满天飞、审核磨人的写作平台，真的建议你可以试试，借助大模型，搭一个属于自己的小地方。过程比想象中简单，结果比想象中满足
